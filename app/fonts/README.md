These unmodified variable fonts are bundled for offline, reproducible builds
using `next/font/local` in `app/fonts.ts`.

- Roboto: https://github.com/google/fonts/tree/main/ofl/roboto
- Roboto Mono: https://github.com/google/fonts/tree/main/ofl/robotomono

Each font's SIL Open Font License is included alongside its font file.
