# COVERAGE_MATRIX.md — Global Admin Control Plane, §1–§33

> **A material caveat before anything else, because Part 1 asked for candour over an optimistic
> row.** The original CTO specification document (§1–§33, the source this matrix is meant to audit
> against) was never persisted to disk in this repository — `docs/admin/BRIEF-GLOBAL-ADMIN.md` was
> named as its destination on day one, but the file does not exist and has no git history. What
> survives is: (a) every verbatim fragment this project's own docs and code comments quoted from it
> while building each phase, and (b) the fragments the Phase 9 brief itself quotes directly. That is
> real evidence, not a guess, for every row below that cites a quoted fragment — but it is fragments
> of the source document, not the source document. Two sections (**§17, §22**) have **zero**
> citations anywhere in nine phases of this project's own documentation or code comments — meaning
> either they were never relevant to anything built, or they were missed entirely. There is no way
> to tell which from here. **If the original document can be located or re-supplied, this matrix
> should be re-run against it — every row, not just §17/§22 — since a fragment quoted for one
> purpose in Phase 3 may have silently dropped context relevant to a requirement in Phase 6.**
>
> Status legend: `IMPLEMENTED` · `PARTIAL` (with what remains) · `MISSING` (spec'd, not built) ·
> `DECLARED_NOT_POSSIBLE` (real data/infra reason) · `TEXT UNAVAILABLE` (no quoted fragment exists
> to audit against — implementation may still be complete or absent, but this matrix cannot judge).
