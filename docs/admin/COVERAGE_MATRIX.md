> row.** The original CTO specification document (§1–§33, the source this matrix is meant to audit
> against) was never persisted to disk in this repository — `docs/admin/BRIEF-GLOBAL-ADMIN.md` was
> named as its destination on day one, but the file does not exist and has no git history. What
