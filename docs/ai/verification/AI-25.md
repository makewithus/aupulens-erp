## 9. Bugs found and fixed

1. **Missing/malformed `period` in the event payload crashed with an uncaught Mongoose cast exception — the identical defect shape fixed in AI-14, reproduced and fixed here too.** `observe()` did `String(event.payload.period)` with no validation, exactly like AI-14's pre-fix code (same `period.horizon.reached` payload contract). Reproduced directly before the fix via a standalone script: `runWorkflow(ai25WorkingCapitalIntelligence, {payload: {}})` threw `Cast to date failed for value "Invalid Date" ... at path "header.date"` — the same crash, same root cause (a literal `"undefined"` string reaching `Date.UTC(NaN, NaN, ...)` inside `extract()`'s period-bounds construction). **No cheap NL keyword currently routes to AI-25 with empty parameters** (confirmed: no AI-25 entry in `workflowIntentMap.ts`), so this bug is not yet reachable through a documented conversational path the way AI-14's was — but nothing upstream of `extract()` validates the payload either, and a future chat mapping, a hand-built event, or a scheduled re-run with a malformed period would hit the identical crash. **Root-cause fix**: `observe()` now validates `event.payload.period` against the same `/^\d{4}-(0[1-9]|1[0-2])$/` pattern and defaults to the current calendar month (UTC) when missing or malformed, deriving `periodEnd` from the resolved period rather than trusting a second, independently-malformed field — identical fix shape to AI-14's. **Regression test** (`tests/ai/aiRuntime/ai25WorkingCapitalIntelligenceEdgeCases.test.ts`): "bug regression: a missing or malformed period degrades to the current period instead of crashing" — exercises `undefined`, `"undefined"`, `"not-a-period"`, `"2026-13"`, `"2026"`, and `""`, all resolving cleanly. Passes; the existing fixture suite remains green. **Class, not incident — confirmed present in a sibling in this same pass**: this is the exact same defect independently found and fixed in AI-14 in this same session (see AI-14's verification record §9) — both workflows share the identical unvalidated-payload shape, both are in this task's scope, both were fixed. **Flagged, not fixed** (out of scope): the same shape plausibly exists in every other `period.horizon.reached`-consuming workflow outside this chunk's four (AI-11, AI-12, AI-13, AI-17 through AI-24, AI-28, AI-29) — named as a suspicion for the requester to check, not independently confirmed for those workflows in this pass.
