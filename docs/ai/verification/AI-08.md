## 5. Failure paths

- **Missing config** (no prepaid/deferred account): escalates with a named finding, no schedule guessed (§4, C.4).
- **Locked period**: caught, period left pending, no partial write (§4, C.3/C.5).
- **Kill switch off**: clamps to RECOMMEND, candidate still surfaced, no write (§4, C.4).
- **Permission denied**: clamps to RECOMMEND via the shared gate.
- **Tool failure mid-pipeline**: caught generically, no partial write, retried next sweep.
- **Model unavailable**: not applicable — no model calls.
- **Malformed source data**: covered, no crash (§4, C.1).
- **Cancelled source document**: dedicated finding (HIGH severity), schedule suspended rather than run — the workflow's own best-in-class failure path among these three (§4, C.3).
- **Missing/cross-tenant subject record**: `extract()` throws, executor marks the run `failed` with a finalized trace — same mechanism as AI-04/AI-07 (§9).

## 9. Bugs found and fixed

**Bug 1 — cross-tenant data leak in `extract()`, two locations (FIXED).** Identical defect shape
to AI-04's Bug 1 and AI-07's Bug 1: `detect`'s `Invoice.findById(observed.raw.recordId)` and
`execute`'s `AiSchedule.findById(observed.raw.scheduleId)` both had no `tenantId` filter.
`execute`'s exposure mirrors AI-07's reversal_run finding exactly — `subscriptionFilter`'s
ownership check is bypassed entirely on the direct-`runWorkflow()` path
(`lib/aiRuntime/nl/chatBridge.ts::runWorkflowFromChat()`).
**Root-cause fix**: both queries now scope to `{_id, tenantId: ctx.tenantId}`.
**Regression tests**: two tests in `ai08PrepaidScheduleEdgeCases.test.ts`, one per branch, each
asserting the run throws/escalates and no schedule/journal is created under the attacking tenant.
**Same class checked elsewhere**: found and fixed identically in AI-04 (one location) and AI-07
(two locations) — see those records' §9 for the full cross-workflow note and the report to the
task owner for the other 27 workflows.

**Finding 2 (trigger-wiring gap, REPORTED, NOT FIXED — out of scope)**: same as AI-07's record §9 —
`app/api/finance/bills/route.ts` never emits `bill.created`.

**Finding 3/4 (shared-executor issues, REPORTED, NOT FIXED — out of scope)**: identical to AI-04
