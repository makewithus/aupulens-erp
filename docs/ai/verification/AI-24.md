## 5. Failure paths

- **Missing config**: no `AiMaterialityPolicy` — degrades to the domain checks' own no-materiality
  branch, never an assumed default (section 4, C.4).
- **Locked period**: N/A — AI-24 never touches a locked accounting period (section 4, C.3).
- **Kill switch off**: dispatches at OBSERVE per Hard Rule 6 (OBSERVE-level output is never a
  write), no partial state.
- **Permission denied**: each `rt.callTool()` in `act()` is independently caught — "No acting user
  / permission denied — the finding above still surfaces this" (source comment), never a silent
  drop of the underlying assertion result.
- **Tool failure mid-pipeline**: proven by the concurrency test (section 4, C.3) — a losing
  concurrent call converges on the same idempotency-keyed state rather than a partial write; the
  run either fully succeeds or finalizes an audited `FAILED` trace (generic executor guarantee).
- **Malformed source data**: proven not to crash by the malformed-payload regression test (section
  9) — a garbage `period`/non-ISO `periodEnd` never reaches `Date.UTC()` as `NaN`.

Every path escalates or no-actions cleanly — never throws into a business route, never partially
writes.
